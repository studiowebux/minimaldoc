## Status Page Features

MinimalDoc includes a built-in status page system for tracking service health:

- Component-based status tracking
- Incident management with timeline
- Historical uptime data
- RSS feed for status updates

## Configuration

Status pages are configured in `config.yaml` and populated from YAML data files. No external services required.
