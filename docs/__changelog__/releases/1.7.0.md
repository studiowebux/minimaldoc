## Changed

### OpenAPI Parser Migration

- Replaced `kin-openapi` with `libopenapi` for OpenAPI spec parsing
- Native OpenAPI 3.1 support (type arrays, nullable via type union)
- Continued full support for OpenAPI 3.0.x specs
- Added parser tests covering OAS 3.0, OAS 3.1, and `$ref` preservation
