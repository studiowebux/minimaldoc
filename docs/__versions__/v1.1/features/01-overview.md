# Features Overview (v1.1)

MinimalDoc v1.1 includes all v1.0 features plus new additions.

## New in v1.1

| Feature | Description |
|---------|-------------|
| Knowledge Base | Self-service support hub with categories and search |
| Markdown landing sections | Define landing sections in `__landing__/*.md` files |
| Windows builds | Native Windows binary support |
| Version display | MinimalDoc version badge in footer |
