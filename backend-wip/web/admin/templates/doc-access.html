How It Works

Path Patterns

Use glob patterns to match documentation paths:

  • /docs/internal/* - Matches any file directly in /docs/internal/
  • /docs/internal/** - Matches all files recursively under /docs/internal/
  • /docs/api/v2/* - Matches files in /docs/api/v2/

Role Hierarchy

Users with higher roles automatically have access to lower-role content:

  • admin - Full access to everything
  • editor - Can access editor, author, and viewer content
  • author - Can access author and viewer content
  • viewer - Basic authenticated access

Client Integration

Add this to your static site to enable private docs checking:

<script>
MinimalDoc.init({
  endpoint: 'https://api.example.com',
  siteId: 'your-site-id',
  features: ['analytics', 'private-docs']
});
</script>
