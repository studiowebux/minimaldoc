# Welcome to MinimalDoc

**MinimalDoc** is a fast, minimal static site generator designed specifically for documentation. It converts your Markdown files into beautiful, responsive documentation websites.

## Why MinimalDoc?

### Simple & Fast
Write your documentation in Markdown and generate a complete site in seconds. No complex configuration, no unnecessary features.

### Beautiful Design
Clean, distraction-free design with built-in dark mode support. Fully responsive for all devices.

### Developer Friendly
- Syntax highlighting for code blocks
- Custom admonition blocks for notes and warnings
- Automatic table of contents generation
- Full-text search with keyboard shortcuts

### LLM Optimized
Automatically generates LLM-friendly documentation files for AI assistants and chatbots.

## Key Features

- **Markdown-based** - Write in plain Markdown
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Dark Mode** - Built-in theme switcher
- **Search** - Client-side search with Cmd+K shortcut
- **Navigation** - Auto-generated from file structure or custom TOC
- **Syntax Highlighting** - Beautiful code blocks
- **SEO Friendly** - Auto-generated sitemap and meta tags
- **Zero Config** - Works out of the box
