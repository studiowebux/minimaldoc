# Pet Store Documentation

Welcome to the Pet Store API documentation! This is a comprehensive guide to using our REST API.

## Features

- **Pet Management**: Create, read, update, and delete pets
- **User Management**: Register and manage users
- **Order System**: Place and track orders

## Getting Started

To get started with the Pet Store API, you'll need:

1. An API key or JWT token
2. A REST client (curl, Postman, or our interactive docs)
3. Basic understanding of REST APIs

## API Reference

Check out our [API Reference](/api/openapi) for detailed endpoint documentation with interactive testing.

## Authentication

The API supports two authentication methods:

- **Bearer Token (JWT)**: For user-specific operations
- **API Key**: For application-level access

See the API reference for specific security requirements per endpoint.
